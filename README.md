# «Зерно» — концепт интернет-магазина обжарочной мастерской

Демонстрационная витрина интернет-магазина для вымышленной обжарочной мастерской «Зерно»: кофе в зёрнах и дрип-пакеты. Проект сделан как пример работы — магазин не настоящий, заказы не принимаются, данные из формы никуда не отправляются.

## Функции

- **Шапка** с логотипом, навигацией, живым поиском и иконкой корзины со счётчиком товаров.
- **Первый экран** с рисованными упаковками и ключевыми преимуществами.
- **Каталог из 12 товаров**: страна происхождения, степень обжарки, вкусовые ноты, обработка, высота произрастания; фасовки 250 г / 1 кг (для дрип-пакетов — 10 / 25 шт.) с разными ценами.
- **Изображения товаров нарисованы кодом** (inline SVG) — у каждой пачки свой цвет, без внешних картинок.
- **Фильтры**: категория, степень обжарки, диапазон цен (поля и ползунок); счётчик активных фильтров и сброс.
- **Сортировка**: по популярности, по возрастанию и убыванию цены.
- **Живой поиск** по названию, стране, вкусовым нотам и категории (без учёта регистра и «ё»).
- **Карточка товара** в модальном окне: выбор фасовки, количество, итоговая цена.
- **Корзина** в выезжающей панели: изменение количества, удаление с возможностью вернуть товар, подытог, шкала до бесплатной доставки (от 3000 ₽). Корзина сохраняется в `localStorage` и синхронизируется между вкладками.
- **Оформление заказа**: имя, телефон с маской, способ получения (курьер, пункт выдачи, самовывоз), адрес; валидация с понятными сообщениями и экран успешного оформления.
- **Пустые состояния** для каталога и корзины, всплывающие уведомления.
- **Доступность**: подписи полей, управление фокусом и ловушка фокуса в модальных окнах, закрытие по Esc и клику по фону, видимый фокус, ссылка «Перейти к каталогу».
- **Адаптивная вёрстка** от 360 px без горизонтальной прокрутки; плавные микроанимации, которые отключаются при настройке «уменьшить движение».

## Стек

- HTML5, CSS3 (CSS-переменные, Grid, Flexbox), JavaScript без фреймворков.
- Без сборки и зависимостей; из внешних ресурсов — только шрифты Google Fonts (Lora и Manrope).

## Структура

```
coffee-shop/
├── index.html   — разметка страницы
├── style.css    — стили и адаптив
├── data.js      — каталог товаров
├── script.js    — каталог, фильтры, корзина, оформление заказа
└── README.md
```

## Как открыть

- **Локально**: скачайте папку и откройте `index.html` двойным щелчком в любом современном браузере — сервер не нужен.
- **GitHub Pages**: загрузите содержимое папки в репозиторий и включите Pages в настройках (Settings → Pages). Все пути относительные, поэтому сайт работает и из подпапки.
